# LEES DIT EERST — uploaden naar GitHub

## In het kort

Pak deze zip uit en upload **alle 27 bestanden** naar je GitHub-repository.
Ze moeten allemaal in de hoofdmap staan, niet in submappen.

## Stap voor stap

1. Pak de zip uit op je computer.
2. Ga naar je repository: **github.com/Bflyer-ops/ABFY-**
3. Klik op **Add file** → **Upload files**.
4. Selecteer **alle** uitgepakte bestanden en sleep ze in één keer in het
   uploadvak. Bestaande bestanden worden automatisch overschreven.
5. Scroll naar beneden en klik op **Commit changes**.
6. Vercel deployt binnen een minuut automatisch opnieuw.

## Oude bestanden opruimen

Staan deze nog in je repository? Verwijder ze — ze worden niet meer gebruikt:

- de map `css/` (indien aanwezig)
- de map `js/` (indien aanwezig)

Verwijderen doe je door op het bestand te klikken → prullenbakicoon → **Commit
changes**.

## Wat je daarna nog moet doen

Twee dingen die je zelf moet afronden, allebei kort:

1. **Contactformulier activeren.** Vul op de live site het formulier één keer
   zelf in. Je krijgt dan een bevestigingsmail van FormSubmit op
   BK-abfy@hotmail.com — klik die link aan. Pas daarna komen berichten binnen.
   Details staan in `README.md`.

2. **Huisnummer en postcode invullen.** Zie stap 3 in `SEO-HANDLEIDING.md`.

En als je één ding doet voor je vindbaarheid: maak een **Google Business
Profile** aan. Dat levert voor een lokaal kantoor meer op dan alles wat er in
de code staat. Uitleg staat bovenaan `SEO-HANDLEIDING.md`.
